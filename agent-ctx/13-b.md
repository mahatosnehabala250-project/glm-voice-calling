1. **Header** - Gradient BarChart3 icon + "Analytics" title + description + "Last 30 days" badge
2. **4 Key Metric Cards** (2x2 mobile, 4-col desktop):
   - Total Calls (emerald, trend arrow +12%)
   - Appointments Booked (teal, conversion rate %)
   - Avg Call Duration (amber, "2m 15s" format)
   - Revenue Collected (emerald, ₹ formatted, trend +18%)
3. **Call Volume Trend** - 7-day AreaChart with emerald gradient (calls) + amber gradient (bookings)
4. **Appointment Status Breakdown** - Donut/PieChart with Confirmed (emerald), Pending (amber), Cancelled (rose), Completed (slate) + percentage labels
5. **Call Intent Distribution** - 5 animated horizontal bars (emerald→teal gradient) for Appointment Booking, General Inquiry, Rescheduling, Emergency, Other
6. **Call Sentiment Analysis** - 3 sentiment cards (Positive/ThumbsUp emerald, Neutral/Minus amber, Negative/ThumbsDown rose) with percentage + count
7. **Peak Calling Hours** - BarChart (8AM-8PM) with amber gradient bars, rotated labels
8. **Weekly Performance Table** - 7-day table (Day | Calls | Bookings | Conv. Rate | Revenue) with Today row highlighted, max-height scroll, color-coded conversion rates
